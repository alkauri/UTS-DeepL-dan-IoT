SESI I: Patterns of Data with Analysis and AI
--------------------------------------------------------------------------------
[STUDI KASUS]
Customer Churn Predictive Analytics & Data Cleaning Pipeline

[TUJUAN AI AGENT]
Membuat skrip Python yang melakukan pembersihan data (data cleaning) mendalam dan 
membangun model prediktif dasar untuk menganalisis risiko churn pelanggan.

[PROMPT UNTUK AI AGENT]
Bertindaklah sebagai Data Scientist profesional. Buatlah sebuah proyek Python di 
direktori lokal dengan struktur file berikut:
1. data_preprocessing.py: Script untuk memuat dataset mentah (gunakan dataset 
   dummy/CSV publik seperti Telco Customer Churn), menangani missing values, 
   melakukan normalisasi, dan encoding fitur kategorikal.
2. train_model.py: Script untuk membagi data (train-test split), melatih model 
   Logistic Regression dan Random Forest, serta mengevaluasi performa menggunakan 
   Confusion Matrix dan Accuracy Score.
3. requirements.txt: Berisi dependencies (pandas, numpy, scikit-learn).
Pastikan kode modular, bersih, dan diberi komentar lengkap di setiap bagiannya.

[PANDUAN GIT & GITHUB]
Inisialisasi git lokal (`git init`), tambahkan semua file (`git add .`), buat 
commit pertama (`git commit -m "feat: complete data analysis and churn prediction pipeline"`), 
lalu hubungkan ke repository GitHub baru dan lakukan push (`git push origin main`).

SESI II: Global Infrastructure to Address Local Challenge with HPC
--------------------------------------------------------------------------------
[STUDI KASUS]
Modular Pipeline untuk Analisis Data Kualitas Udara/Cuaca Lokal

[TUJUAN AI AGENT]
Membangun arsitektur perangkat lunak berbasis modular untuk mengambil, memproses, 
dan menyimpan data lingkungan lokal (misalnya data cuaca/polusi udara) secara efisien.

[PROMPT UNTUK AI AGENT]
Bertindaklah sebagai Software System Integrator. Buatlah program Python modular 
dengan struktur:
1. fetcher.py: Modul untuk melakukan pengambilan data (HTTP Request) dari API 
   publik terkait data lingkungan/cuaca lokal (misalnya OpenWeather API atau data dummy publik).
2. processor.py: Modul untuk membersihkan dan mentransformasikan struktur data 
   JSON mentah menjadi format tabel terstruktur menggunakan Pandas.
3. main.py: Skrip utama yang menjalankan pipeline secara berurutan dan menyimpan 
   hasilnya ke file CSV lokal atau database SQLite.
Pastikan penanganan error (error handling) diimplementasikan dengan baik untuk 
mengantisipasi kegagalan koneksi jaringan.

[PANDUAN GIT & GITHUB]
Lakukan git staging (`git add .`), buat commit dengan pesan 
`git commit -m "feat: modular environmental data processing pipeline"`, dan push ke repository GitHub Anda.

SESI IV: Introduction to Machine Learning
--------------------------------------------------------------------------------
[STUDI KASUS]
Supervised Learning Pipeline & Model Evaluation untuk Klasifikasi

[TUJUAN AI AGENT]
Membangun alur kerja Machine Learning end-to-end mulai dari preprocessing, 
pelatihan model klasifikasi, hingga evaluasi untuk mendeteksi overfitting.

[PROMPT UNTUK AI AGENT]
Bertindaklah sebagai Machine Learning Engineer. Buatlah file `ml_pipeline.py` 
menggunakan Scikit-Learn dengan tahapan berikut:
1. Load dataset klasifikasi standar (misalnya Iris atau Breast Cancer dari `sklearn.datasets`).
2. Lakukan train-test split (80:20) dan standarisasi fitur menggunakan `StandardScaler`.
3. Latih model Decision Tree dan Support Vector Machine (SVM).
4. Evaluasi model dengan membandingkan Training Accuracy vs Testing Accuracy 
   untuk mendeteksi potensi overfitting, serta cetak `classification_report`.

[PANDUAN GIT & GITHUB]
Lakukan commit dengan pesan `git commit -m "feat: complete ML supervised classification and overfitting analysis pipeline"` 
dan push ke GitHub.
